API Reference

Endpoints de pantallas Smart TV publicados por la demo:

  • GET /api/tv-feed · feed para la pantalla Smart TV
  • GET /api/tv/status · estado de emparejamiento de las pantallas
  • POST /api/tv/pair · empareja una pantalla Smart TV
  • POST /api/tv/unpair · desvincula una pantalla Smart TV

Prueba rápida:

https://biomedica-smarttv.onrender.com/api/tv/status
