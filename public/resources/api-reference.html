API Reference

Endpoints principales publicados por la demo:

  • GET /api/status · estado actual del wearable activo
  • GET /api/devices · inventario de wearables y TVs
  • GET /api/tv-feed · feed para la pantalla Smart TV
  • POST /api/telemetry · envío de telemetría desde smartwatch
  • POST /api/select-wearable · cambia el wearable activo
